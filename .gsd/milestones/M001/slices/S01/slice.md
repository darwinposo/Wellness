## Demo Sentence
After this slice, the user can see the full Reflect color system, typography scale, and base component library applied consistently across sample screens in Figma — and export the token JSON that generates the NativeWind config.

## Boundary Map

### Produces
- Figma Variables: `Primitives` collection (raw color/spacing values)
- Figma Variables: `Semantic` collection (role-based tokens, light + dark modes)
- Figma component library: Buttons, Inputs, Cards, Tab Bar, Header, Modal shell
- `design/tokens/tokens.json` — exported from Figma via TokenFlow plugin
- `design/tokens/tailwind.config.js` — generated by Style Dictionary from tokens.json
- `design/tokens/global.css` — CSS custom properties for NativeWind

### Consumes
- Research specs from `.gsd/milestones/M001/slices/S01/research.md` (color palette, typography, spacing)

## Tasks
- T01: Color system + typography in Figma Variables
- T02: Base component library (all reusable UI primitives)
- T03: Token export pipeline (Figma → JSON → NativeWind config)
